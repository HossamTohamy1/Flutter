# 📱 Shopping App (Flutter)

> A mobile shopping app: browse products, add them to your cart, check out, and follow your orders — from your phone.

---

## 🧐 What is this, in plain words?

This is a **phone app** for an online store. It works on Android and iPhone (and also on web and desktop) from the same code.

With it you can:

- 🔐 **Sign up / log in**.
- 🏷️ Browse **products** by **category** and open product details.
- 🛒 Add items to your **cart**.
- 💳 **Check out** and get an **order confirmation**.
- 📦 See your **orders** and their details.
- 👤 Edit your **profile**.

Store managers can also **add / edit products and categories** right from the app.

## 👥 Who uses it?

| Who | What they can do |
|---|---|
| **Shopper** | Browse, add to cart, order, track orders, edit profile |
| **Store manager** | Add and edit products and categories |

---

## 🛠️ For developers

**Tech stack:** Flutter · Dart · Provider (state management) · `http` for API calls · Google Fonts · Repository pattern

**Code structure (`lib/`):** `screens`, `widgets`, `models`, `providers`, `repositories`, `services`, `config`

**Run locally**

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Set the back-end URL in `lib/config/api_config.dart`.
3. Run:
   ```bash
   flutter pub get
   flutter run
   ```
